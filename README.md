## 🚀 安装

1. 🧩 打开侧栏 **插件**（Plugins）页。
2. 📃 点 **添加插件**（Add plugin）旁的箭头，选 **安装第三方插件**（Install a third-party plugin）。
3. ✅ 输入 `dsh-everforest` 安装，装好后点 **立即启用**。

## 🔥 特性

- 🌳 颜色以柔和的鼠尾草绿与暖米色为主调，自然耐看。
- 🎨 按 DSH 的颜色 token 逐项映射，深浅两套各自优化对比度。
- 🖌️ 聊天内容着色：标题、强调、行内代码、链接、表格各用不同颜色，6 档配色各有自己的方案。
- 🌓 深色 / 浅色 / 跟随系统，随意切换。
- 📄 工作区会话列表按状态着色：待确认 / 已完成一眼分辨。
- ⌛️ 首次加载页（loading 页与 spinner）已用当前配色，启动更自然。
- ⚙️ 打开 **Settings → Everforest**，可选 6 档强度：
  - 深色：
    - **Soft（默认）** 对比度最低、最柔和；
    - **Medium** 对比度适中；
    - **Hard** 对比度最高、清晰锐利。
  - 浅色：
    - **Soft** 对比度最低、最柔和；
    - **Medium** 对比度适中；
    - **Hard（默认）** 对比度最高、阅读更清晰。
